# מערכת לניהול חיילים (Soldier Management System) 🪖

מערכת API מלאה ומקצועית לניהול מאגר מידע של חיילים, המבוססת על תשתית **FastAPI**. המערכת מאפשרת לבצע פעולות CRUD מלאות (יצירה, קריאה, עדכון ומחיקה) מול קובץ בסיס נתונים מקומי בפורמט JSON, וכוללת מערכת רישום לוגים (Logging) מתקדמת למעקב וניטור בזמן אמת.

---

## 🚀 תכונות מרכזיות
* **ניהול חיילים מלא (CRUD):** * צפייה ברשימת כל החיילים במערכת.
  * שליפת מידע על חייל ספציפי לפי מזהה ייחודי (`id`).
  * רישום והוספת חייל חדש למערכת עם וולידציה על כפילות מזהים.
  * עדכון פרטי חייל קיים (שם מלא ודרגה).
  * מחיקת חייל מהמערכת.
* **ניהול קבצים וקלט/פלט (I/O):** שמירה וטעינה אוטומטית מול קובץ `soldiers.json` בצורה בטוחה ומסודרת.
* **רישום לוגים מתקדם (Comprehensive Logging):** תיעוד של כל פנייה, שגיאה או פעולה מוצלחת במערכת הן לתוך קובץ לוג ייעודי (`system.log`) והן לקונסול (Terminal).
* **טיפול בשגיאות (Error Handling):** החזרת קודי סטטוס HTTP מתאימים (כמו `404 Not Found`, `400 Bad Request`, ו-`409 Conflict`) בצירוף הודעות מפורטות במקרה של קלט לא תקין או בעיות לוגיות.

---
